Color carries meaning. Use it intentionally.

## Start with neutrals
Most of your interface should be neutral, with a single accent color for emphasis.

## Check contrast
Aim for at least a 4.5:1 contrast ratio for body text.

## Support dark mode
Define colors as CSS variables so you can swap them with `prefers-color-scheme`.
